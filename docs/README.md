# 使用与维护文档

这份目录面向收到源码包的部署者、调用者和后续开发者。工具包独立运行，直接CLI和标准MCP共用实现；任何具体智能体宿主都是可选调用方。

## 按一条完整流程阅读

1. [配置与部署](配置与部署.md)：解压、首次准备、已有环境、配置优先级、工作区和远程部署。
2. [使用指南](使用指南.md)：公开例题、自有算例、单次计算、扫描、结果与报告，直到拿到文件。
3. [产物与清理](产物与清理.md)：相对路径的基准、隐藏目录、日志与原始结果、维护清理和删除边界。
4. [故障排查](故障排查.md)：定位配置、计算、统计、报告转换和连接问题。

需要程序接入或修改时：

- [MCP服务与接口](MCP服务与接口.md)：标准发现/调用、鉴权、错误、路径与确认要求，SDK客户端示例。
- [工具接口参考](工具接口参考.md)：从实际注册表生成的工具清单、参数默认值及完整输入Schema。
- [架构与扩展](架构与扩展.md)：源代码职责、执行链路、加函数/工具/模板/资料的入口和验证方法。
- [测试与验收说明](测试与验收说明.md)：工程检查、真实OpenMC测试、专业验证与正式验收的区别。

## 可选与项目管理材料

- [宿主平台接入](MCP平台接入.md)：Codex、DSH等扩展示例，不是工具包运行的前置条件。
- [公开资料、例题与修复](公开资料与例题修复.md)：固定官方资料、例题来源、逐次确认修复的详细流程。
- [OpenMC工具使用说明](OpenMC工具使用说明.md)：已有逐项操作示例，可与新使用指南配合查阅。
- [验收导向开发计划](验收导向开发计划.md)、[实施与验收边界](实施与验收.md)：合同功能状态与待协作输入，不是面向所有下游的新增使用条件。

文档中的部署默认值和示例参数是工程配置，实际生效值以服务端配置和返回值为准；没有把它们新增为验收指标。
