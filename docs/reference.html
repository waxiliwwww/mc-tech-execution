返回怎么看

MCP调用同时给服务启动快照service（version/startup_version/current_disk_version/version_matches_disk/code_matches_disk/current_code_fingerprint/changed_files/restart_required）和实时探测；任一不一致时warnings给出重启提示，不能把旧进程的工具清单当成磁盘新版本。openmc_version_matches只检查OpenMC；package是CLI调用时磁盘身份，CLI不返回在线服务快照。workspace为服务端绝对工作区；cross_sections_env_set仅检查环境变量，实际核数据须继续模型校核。

判读字段含义与继续条件
expected_version / api_version / executable_version_outputOpenMC引擎的预期/API/可执行程序版本，不是工具包服务版本。
openmc_version_matches只检查OpenMC可执行程序版本，不是工具包服务版本；MCP调用读取service.version，与包内VERSION对照。
service.name / service.version / service.version_sourceMCP调用由服务端加入启动时固定的服务名、版本及mcp_server_startup来源，与握手和/health同源；不会随磁盘VERSION更新。CLI直接调用没有此字段，不能据此判断在线服务。
service.startup_version / current_disk_version / version_matches_disk启动快照与当前磁盘版本对照；false时不能认为旧进程已经加载新版本。
service.startup_code_fingerprint / current_code_fingerprint / code_matches_disk / changed_files启动时产品Python模块及model_validation/schema.json指纹与当前磁盘对照；只列相对包路径，不读取或回显文件内容。
service.restart_required / ready_for_new_operations / warnings版本/产品代码或模型Schema不一致时提示重启并阻止新操作；查询和取消保留。ready_for_new_operations=false时不要提交。旧进程没有检测器的字段缺失应记未核实，先更新服务。
cross_sections_configured / cross_sections_env_set均表示OPENMC_CROSS_SECTIONS环境变量是否设置，不是核数据可用性判据。false可以使用nuclear_data指示的受管候选索引；index_exists仍不证明数据齐备，先核对模型核素/热散射名称与索引匹配；静态语义不检查HDF5文件完整性，由部署者按生效索引另核对。
