参数类型必填省略或默认含义与来源填写示例
case_dirstring是不可省略算例目录，相对服务端MC_WORKSPACE（默认包根目录/workspace），不是客户端路径。读取已有算例；生成接口要求目标尚不存在。可沿用准备例题返回的case_dir。"cases/my-case"
